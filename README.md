## 🧠 Como rodar o projeto

1. Clone o repositório (se tiver coragem)
2. Dê `npm install` e reze pra não quebrar
3. Rode `npm start` e faça um café
4. Torça pra não aparecer erro na tela do usuário final

> Se der pau, a culpa é do **cache** ou do **sênior que desligou o servidor sexta 18h**.
