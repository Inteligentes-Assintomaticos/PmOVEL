# Condições em JS

## Introdução

As estruturas condicionais permitem que o código tome decisões baseadas em condições específicas, executando diferentes blocos de código.

## If Else

O if else basicamente cosiste em um "se..." (if), "caso não..." (else) e um "caso não, se...".

Esturura básica do if else >>>

```bash

let dia = 1

if (dia === 2) {
    console.log("Terça-Feira")
} if else (dia === 1) {
    console.log("Segunda-Feira")
} else {
    console.log("Não sei que dia é esse...")
}

```
